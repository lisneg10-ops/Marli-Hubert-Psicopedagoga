# Marli-Hubert-Psicopedagoga

Site estático profissional em HTML/CSS, com identidade visual mais forte e conteúdo preparado para publicação no GitHub Pages.

## Como publicar no GitHub Pages
1. Faça commit e push do repositório para o GitHub.
2. Acesse as configurações do repositório e entre em Pages.
3. Selecione a opção "Deploy from a branch".
4. Escolha a branch principal e a pasta raiz como origem.
5. O site ficará disponível em:
   https://seu-usuario.github.io/Marli-Hubert-Psicopedagoga/

## Arquivo pronto para copiar
- O código completo do site está em index.html.
- Uma cópia pronta para uso está em site-completo.html.

Se quiser usar um domínio próprio, crie um arquivo CNAME com o nome do domínio desejado.
